# Project Statement

## Project Description

The Student Academic Performance Analyzer is a command-line python program to facilitate commonly required academic computations. The user enters the student details followed by the marks scored in each of the subjects. The program provides overall marks and average along with grades and pass/fail status. It also includes class ranking, subject-wise statistics and analysis of weak and strong areas.

The present project targets the academic domain to demonstrate the basic python programming concepts in practice.

## Problem Statement

Students often get scores in several subjects but lack the ability to analyze the overall performance. Manually calculating and checking the total, average, strong and weak areas and comparing the class rank is a laborious process and prone to errors.

The proposed Student Academic Performance Analyzer is a console-based program to organize student marks and compute necessary grades.

## Scope

The project scope involves entering student records, validating the marks, computing grades, statistical analysis of each student, class ranking and basic performance analysis.

The project is designed as a console application and does not target institutional-level student information management system.

## Target Users

- Students to evaluate their own academic performance

- Teachers for quick analysis of classroom performance

- Programmers to study python problem-solving approaches

## High-Level Features

- Maintain student database

- Enter/Update subject-wise marks

- Compute grades based on given criteria

- Individual performance reports

- Class and subject statistics

- Rank calculation

- Weak/Strong area analysis

- Input validation and error handling
